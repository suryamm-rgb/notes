## What is an Operating System?

An **OS** is system software that manages computer hardware and software resources and provides common services for computer programs.

**In simple words:** An OS is software that acts as a middleman or bridge between computer hardware and the computer user. It provides a user interface and controls the computer hardware so that software can function.

### Types of OS

- **Desktop OS** — e.g., Microsoft Windows, macOS, and Linux distributions such as Ubuntu
- **Server OS** — Windows Server, Linux distributions like CentOS, Red Hat Enterprise Linux
- **Mobile OS** — Android, iOS, Windows Mobile
- **Embedded OS** — used in devices like medical equipment, car ECUs, aerospace systems, network firewalls, and other critical systems

## What is Linux?

Linux, in simple terms, is a **free and open-source operating system**.

It's similar to Windows and macOS but differs in several ways. Linux is very popular for its **stability, security, and flexibility**. It can be modified and distributed by anyone, which has led to many different versions known as **"distributions,"** each tailored for a different type of user.

Its open-source nature means that a community of developers and users contribute to its development.

### Why Learn Linux? / Why is it Important?

- Widely used in servers and cloud computing
- Free software philosophy
- Strong command-line interface
- Enhanced security
- Highly customizable due to its open-source nature
- Strong community support
- Helps build understanding of other operating systems

## History of Linux

### Before Linux

- **UNIX**: Developed in the 1970s at AT&T's Bell Labs by Ken Thompson and Dennis Ritchie
- **GNU Project**: In 1983, Richard Stallman launched the GNU Project

### Birth of Linux

- **1991**: A 21-year-old Finnish student named **Linus Torvalds** announced he was creating a free OS

### Growth and Evolution

- **Early 1990s**: Linux rapidly evolved through collaboration over the internet
- **1994**: Linux 1.0 was released with 176,000 lines of code
- **Late 1990s**: Commercial interest in Linux grew
- **2000s**: Linux saw significant adoption in server markets
- **2007**: Google released the Android OS for mobile devices, built on the Linux kernel

## UNIX vs Linux

| Aspect | UNIX | Linux |
|---|---|---|
| Origin | First developed for multi-user, multi-tasking systems in the mid-1970s at Bell Labs by AT&T, GE, and MIT | Created in 1991 by Linus Torvalds |
| Cost | Mostly commercial/paid | Mostly free |
| Source | Mostly closed source | Open source |
| Vendors | Sun (Solaris), HP-UX, AIX, etc. | Community/companies (Red Hat, CentOS, Debian, etc.) |
| File system support | Supports comparatively fewer file systems | Supports a wide range of file systems |
| Hardware support | More limited | Can be installed on a wide variety of hardware — mobile phones, tablets, video game consoles, mainframes, and supercomputers |

## Linux vs Windows

| Aspect | Linux | Windows |
|---|---|---|
| **Source code** | Open source | Proprietary software |
| **Cost** | Free | Paid ($$$) |
| **User interface** | Multiple desktop environments available (GNOME, KDE, XFCE, etc.) | Standard GUI consistent across Windows versions |
| **Command line interface** | The console/terminal is at the very core of Linux | Has Command Prompt and PowerShell |
| **Software installation** | Installed using package managers like APT, YUM, Pacman | Mostly installed using standalone executables (.exe) |
| **Security** | Generally considered more secure | Larger user base makes it a more common target for malware; somewhat more vulnerable |
| **Stability & performance** | Known for strong stability and performance | Generally stable but can slow down over time |
| **File systems** | ext4, XFS, Btrfs | NTFS, FAT (primary file systems) |
