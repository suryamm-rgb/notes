# JavaScript — Key Points

## What is JavaScript?
- Lightweight, **interpreted / JIT-compiled** language with first-class functions.
- Best known as the web page scripting language, but also runs in non-browser environments: **Node.js, Apache CouchDB, Adobe Acrobat**, etc.
- **Prototype-based**, garbage-collected, dynamic language.
- Supports multiple paradigms: **imperative, functional, object-oriented**.

## Dynamic Capabilities
- Runtime object construction
- Variable parameter lists
- Function variables
- Dynamic script creation (`eval`)
- Object introspection (`for...in`, `Object` utilities)
- Source-code recovery (functions store source text, retrievable via `toString()`)

## Standards
- **ECMA-262** — ECMAScript Language Specification
- **ECMA-402** — ECMAScript Internationalization API specification
- New proposals are often documented once implemented in browsers (typically between **Stage 3 and Stage 4**), often before official spec publication.

## JavaScript vs. Java
- **Not related** despite the name — JavaScript is not "Interpreted Java."
- "Java" and "JavaScript" are both trademarks of **Oracle** in the US and other countries.
- Different syntax, semantics, and use cases.
