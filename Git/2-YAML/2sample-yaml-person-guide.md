# Sample YAML File - Person Details

```yaml
person:
  name: Surya
  age: 35
  gender: M
  is_student: false
  hobbies:
    - reading
    - travelling
    - hiking
  address:
    street: 123 Main St
    city: Mandya
    state: Karnataka
    zip_code: 12345
```

## Notes
- person is a dictionary.
- name is a string.
- age is an integer.
- is_student is a boolean.
- hobbies is a list.
- address is a nested dictionary.

## YAML Facts
- Extensions: `.yaml` and `.yml`
- YAML is case sensitive.
- YAML uses spaces for indentation.
- YAML is not a programming language.
- YAML is a superset of JSON.
